# Учёт личных финансов — лендинг

Статический адаптивный лендинг второго этапа учебного проекта. Используются **только HTML5 и CSS3**, без JavaScript, библиотек и сборки.

## Файлы

- `index.html` — разметка страницы, навигация, статический пример интерфейса.
- `styles.css` — оформление, адаптивность, диаграмма и индикатор бюджета.

## Запуск

Откройте `index.html` в браузере или запустите Live Server в VS Code. Никаких зависимостей устанавливать не требуется.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий на GitHub.
2. Загрузите `index.html`, `styles.css` и `README.md` в корень репозитория.
3. В **Settings → Pages** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`.
4. Сохраните настройки и дождитесь появления ссылки на сайт.

## Как устроено

Лендинг рассказывает о проблеме, возможностях и пользовательском сценарии будущего приложения. Демонстрационная панель показывает **вымышленные статичные данные за октябрь 2026 года**: доходы 85 000 ₽, расходы 42 500 ₽, остаток 42 500 ₽ и бюджет 55 000 ₽. Список последних операций не является полным перечнем расходов месяца.

Круговая диаграмма построена с помощью CSS `conic-gradient`, прогресс бюджета — стандартным HTML-элементом `progress`. Навигация по разделам работает через якорные ссылки. На мобильных экранах ссылки навигации переносятся на следующую строку; JavaScript не требуется.

Это **не работающее финансовое приложение**: операции нельзя добавлять, суммы не пересчитываются, данные не сохраняются. Работающее приложение будет реализовано на следующих этапах.

## Проверка

- Откройте сайт на компьютере и телефоне (например, при ширине 320, 375, 768 и 1280 px).
- Проверьте навигацию, читаемость, отсутствие горизонтальной прокрутки.
- Убедитесь, что стили загружаются после публикации на GitHub Pages.
